# ChatGPT Iterator

This repository preserves the structured development history of **ChatGPT Iterator**, a Chrome side-panel extension for bounded, observable ChatGPT iteration workflows.

## Branches

- [`chatgpt/history`](../../tree/chatgpt/history) — immutable reconstruction of the canonical Library packages from `v0.0.1-planning-overlay` through `v0.0.25`.
- [`chatgpt/develop`](../../tree/chatgpt/develop) — current product tree and curated repository documentation, based on the reconstructed `v0.0.25` state.

The `main` branch is intentionally kept as a small repository landing page. Product source and reconstructed iteration commits are not merged into `main` automatically.

## Provenance

The exact original `v0.0.0` package was unavailable, so no synthetic `v0.0.0` commit or tag is created. Reconstruction begins with the available `v0.0.1-planning-overlay` artifact and records artifact hashes and normalization decisions in `docs/history.md` on `chatgpt/develop`.
