# ChatGPT Iterator

Chrome Side Panel extension for bounded, durable and observable ChatGPT iteration workflows.

## Branches and versions

- `chatgpt/history` is the frozen semantic product lineage from `v0.0.1-planning-overlay` through `v0.0.25`.
- `chatgpt/develop` starts from `v0.0.25` and is the continuation branch for future work.
- Annotated version tags address each historical checkout directly.
- Remote `main` is maintained separately and is never changed by this handoff package.

## Current baseline

`v0.0.25` closes ROADMAP-0002. The archived project state does not authorize a successor version.

## History quality

Each version commit uses a project-native Conventional Commit derived from the actual previous-to-current file diff and the roadmap/iteration authority for that version. Archive selection, hashes, timestamps, and exact-tree verification are kept outside Git history in the handoff `provenance/` directory.

The exact `v0.0.0` package was unavailable and is not fabricated.
