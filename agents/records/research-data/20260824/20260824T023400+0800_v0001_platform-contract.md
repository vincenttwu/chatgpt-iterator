# ChatGPT Iterator v0.0.1 — platform contract research

## Question

Can the working Tampermonkey iteration automation be re-homed as a Chrome-native, Side-Panel-first application that remains reliable when its ChatGPT target is not the active tab, while preserving short iteration delays and team-standard UI behavior?

## Answer

Yes, with an explicit browser-lifecycle boundary.

The extension can move orchestration, persistence, tab identity and recovery out of the ChatGPT page. It can prevent automatic discard during active runs and observe frozen/discarded state. It cannot force a Chrome-frozen page to execute DOM tasks. Correctness therefore requires event-driven page observation, durable run state and truthful `frozen`/`discarded` states rather than an "always runs in background" claim.

## Frozen platform decisions

1. Chrome 132+ baseline.
2. Manifest V3.
3. WXT + Vue 3 + TypeScript.
4. Global Side Panel as primary UI; toolbar action opens/toggles it.
5. Five top-level workspaces: Run, Queue, Presets, Templates, Settings.
6. CRSniffer Side Panel interaction grammar is mandatory team standard where applicable.
7. Service worker/application layer owns orchestration; Side Panel owns only reconstructable presentation/working-copy state.
8. IndexedDB is durable application datastore; small `chrome.storage` tiers remain purpose-specific.
9. Content script is a thin ChatGPT adapter with centralized selectors and MutationObserver-based semantic events.
10. Run binds to explicit `tabId`; active-tab switches never retarget a run.
11. Active runs may temporarily set `autoDiscardable: false`, restoring the previous value on termination.
12. `frozen` and `discarded` are explicit runtime states; frozen DOM execution cannot be bypassed by extension architecture.
13. 5–29 second delays use a persisted `nextDueAt` plus short service-worker timer; alarms are coarse recovery/long-delay scheduling only because packaged alarms have a 30-second minimum.
14. Presets and Templates use stable IDs and the team-standard working-copy lifecycle.
15. Queue mode is a sibling message source to Repeat, not a special-case loop.
16. Export/import uses a versioned portable format independent from physical IndexedDB version.

## Selector disposition

The working userscript already supplies the critical baseline selectors/behaviors for composer, send, stop, continue and assistant-message observation. They remain reference input, but all selectors move behind one adapter/registry and receive health diagnostics. No other application layer may query ChatGPT DOM directly.

## Research closure

No dedicated multi-version research wave is needed. Remaining external research is targeted per owning implementation step when current Chrome/WXT behavior materially controls correctness.
